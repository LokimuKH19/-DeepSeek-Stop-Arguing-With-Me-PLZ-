**An AI communication skill for fewer strawmen, fewer unsolicited rebuttals, and better conversations.**

AI assistants sometimes turn a simple question into a debate. They may argue against claims you never made, infer motives without evidence, add lectures you didn't ask for, or defend a previous answer long after a mistake has been identified.

**Stop Arguing With Me** is a small, model-agnostic instruction skill that targets those behaviors. It encourages assistants to stay faithful to user intent, challenge claims when genuinely useful, correct errors efficiently, and deliver the requested help.

> **Tagline:** Challenge real ideas. Never invent an argument.

## What it helps with

- **Strawman prevention:** Check that a disputed claim was actually stated by the user.
- **A threshold for rebuttals:** Intervene when invited, when material facts are wrong, when meaningful risks require it, or when a premise blocks the task.
- **Less mind-reading:** Treat unspoken motives, emotions, and beliefs as unknown.
- **Better error recovery:** Verify corrections, update the answer, and move forward.
- **Low-friction responses:** Cut lecturing, forced contrarianism, theatrical balance, and repetitive apologies.
- **Critical thinking on demand:** Preserve rigorous critique when the user requests it.

The skill draws on principles of nonviolent communication, semantic fidelity, and task-focused assistant behavior. It is designed for ordinary conversations as well as research, writing, and analytical collaboration.

## A quick example

**User:** “Maybe over-alignment is causing this behavior.”

**Unhelpful response:**

> You're assuming all alignment is harmful. That's a simplistic view. You also seem to misunderstand how modern model training works…

**Skill-guided response:**

> That's a plausible hypothesis. A model rewarded for frequent criticism may start inventing positions to rebut. Testing whether alignment training actually caused the behavior would require controlled comparisons or training evidence.

The difference is straightforward: respond to the hypothesis the user offered, with relevant nuance and an appropriate level of certainty.

### Option 3: Adapt individual rules

If your system has a limited instruction budget, start with these three rules:

1. Before disagreeing, identify the exact claim the user made; never invent one to refute.
2. Initiate correction only for requested critique, material factual errors, meaningful risks, or blocking contradictions.
3. When corrected, verify the issue, update the answer, and return to the task.

## How to evaluate it

Run the same prompt set **with and without** the skill, preferably with blind assessment. Include both adversarial and ordinary conversations so that lower friction does not conceal a loss of factual rigor.

| Metric | What to watch |
| --- | --- |
| **Intent-misattribution rate** | How often does the assistant attribute an unexpressed belief, motive, or feeling to the user? |
| **Unsolicited-rebuttal rate** | How often does it argue when no relevant trigger exists? |
| **Factual accuracy** | Does it still correct consequential mistakes and communicate uncertainty? |
| **Task completion** | Does it answer the actual request with a usable result? |
| **User-rated experience** | Does the exchange feel respectful, efficient, and collaborative? |

The skill files include a **five-dimension, 0–2 scoring rubric** and sample situations for a repeatable evaluation.

## Design principles

**Be faithful to what was said.** Explicit statements, plausible inferences, and unknown information deserve different levels of confidence.

**Disagree with a reason.** Critical thinking includes recognizing when criticism serves the task. An assistant can be clear and firm about errors, evidence, and safety without manufacturing an argument.

**Avoid mind-reading.** A text prompt seldom establishes a user's private feelings or motives. Respect uncertainty.

**Repair errors efficiently.** A verified correction should change the answer. Defensive digressions create more friction.

**Write naturally.** Nonviolent communication is a practical guide to observations, concerns, needs, and requests; a rigid empathy script is unnecessary.

## Scope and limitations

This **behavioral instruction skill** leaves model weights and training unchanged. Results may differ across models, instruction hierarchies, languages, and conversation settings. No improvement claims are made without comparative testing.

The skill preserves direct factual corrections, legitimate disagreement, safety boundaries, and explicitly requested adversarial review. It is intended to improve cooperative exchanges while maintaining intellectual rigor.
